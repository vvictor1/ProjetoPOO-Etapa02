Projeto Integrador: Sistema de Gestão de Clínica e Restaurante
Descrição
Este sistema foi desenvolvido como requisito avaliativo da disciplina de Programação Orientada a Objetos (POO). O projeto foca na implementação de boas práticas de desenvolvimento, incluindo:

Encapsulamento: Uso de atributos private e métodos getters para proteção de dados.

Coleções: Utilização de List e Map para otimização de busca e armazenamento.

Integração: Trabalho colaborativo entre membros da equipe para unificação de módulos.

Observação de Execução
Para garantir o correto funcionamento do sistema, o projeto deve ser executado a partir da pasta projeto e não dentro da subpasta src.

Tecnologias Utilizadas

Linguagem: Java

Controle de Versão: Git/GitHub

Documentação: Diagrama de Classes UML (Mermaid)
